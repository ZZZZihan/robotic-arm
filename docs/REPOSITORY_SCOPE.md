# 仓库与交接资料范围

更新于 2026-10-09。本仓库是 `ZZZZihan/robotic-arm` 私有仓库，用于项目维护与交接。用户已明确要求补齐 README 并上传实际使用的相应资料；本说明替代首版“所有 PDF/DLL 均只留本机”的统一规则。

| 类别 | 当前处理 | 说明 |
| --- | --- | --- |
| 当前四轴操作台、测试、构建脚本 | Git 跟踪 | 当前维护源码是 EtherCATDemo 目录，不能被原始示例覆盖 |
| 交接、验证和资料索引 | Git 跟踪 | 明确日期、验证层级及未完成项 |
| 两份核心 PDF、三份已校验 SDK DLL、10 份原始 C# 示例文件 | 只跟踪 `materials/manifest.json` 明列的副本 | 本次交接明确包含；原文件不删除、不修改 |
| 原始 RAR/ZIP、完整解包目录、其他重复版本、升级工具 | 本机保留 | 不需要用于当前 App 构建，没有整包上传 |
| App 构建产物和现场运行日志 | 本机/现场保留 | 新构建放 `.artifacts/`，发布到独立目录 |
| SSH 密钥、账号凭据、远程登录信息、原始现场截图与网络调查 | 不提交 | 由设备管理员另行交接必要访问能力 |
| Python 原型、历史网页工具与课程等独立工作 | 未因本次资料整理自动纳入 | 需单独整理与验证，不冒充当前构建依赖 |

资料文件通过 `.gitignore` 的精确例外纳入，其他 PDF/DLL/EXE/压缩包仍默认忽略。第三方原始示例设置 `-text`，保存原始字节以便 SHA-256 复核。保留所有原权利声明，见 [materials/NOTICE.md](../materials/NOTICE.md)；私有保存不等于获得公开再分发许可。

控制卡端点常量仍保留在当前 Demo 源码中，是设备配置而非登录凭据。维护时不得把 SSH 私钥、口令或访问令牌放到源码、README、截图或日志中。

以后新增资料应记录用途、来源/版本、大小与哈希，并检查是否与已有版本重复、是否包含访问凭据。不要为了方便而提交整个解包目录或运行环境。
