# Tests

这里存放机械臂项目后续可重复的测试用例与测试说明。

建议每个测试至少记录：

- 测试目标和前置条件；
- 输入、期望结果和实际结果；
- 运行命令、源码提交 SHA 和测试夹具/模拟器版本；
- 是否需要 Windows、控制卡、伺服器或真实机械臂；
- 失败时保留原始错误，不把“程序启动”写成“运动功能通过”。

推荐目录：

```text
tests/
  unit/       # 纯离线、快速、可重复
  protocol/   # EtherCAT/控制卡报文或接口契约
  simulation/ # 仿真或固定夹具
  hardware/   # 真实设备联调，单独标注现场条件
```

目前还没有把厂商提供的二进制测试工具纳入版本库；它们留在本机资料目录中，后续测试脚本通过明确路径调用并记录版本/hash。
