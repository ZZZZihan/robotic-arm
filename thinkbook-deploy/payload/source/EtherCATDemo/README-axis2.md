# 轴2圈数测试版 — 2026-10-09

本文仅保留旧圈数测试版的历史操作记录，其中方向待确认等描述反映当时状态。当前版本为“四轴操作台 · 输入修复版”，轴2正向上升、反向下降已获用户现场确认；当前入口和说明见 [README-dashboard.md](README-dashboard.md)，构建与交接见[根 README](../../../../README.md)。不要将下文的旧桌面入口当成当前发布入口。

用户指定：软件下拉列表中的轴2，目标匀速为每秒2个电机转，即120rpm。该速度按本次核对的262144计数/电机转、驱动电子齿轮1:1和卡端比例1:1，换算为524.288 pulse/ms。它约为旧Demo 20 pulse/ms的26.21倍；不是仅将旧速度乘10。

## 操作

1. 正常关闭其他控制程序，再打开桌面“机械臂Demo-轴2圈数120RPM”。程序不会自动连接、初始化、使能或运动。
2. 点击“打开板卡”，默认选择轴2。当前总线若已初始化，不需要为换程序再次初始化。
3. 查看反馈状态；若未使能，单独点击“使能”，待状态稳定。运动入口本身不自动使能。
4. 速度默认120转/分钟，可调低。填写本次电机圈数，初始0圈不能启动。输入范围最高10圈只是软件输入上限，不代表机械安全行程；必须按现场方向与剩余行程填写。
5. 点击“正向走本次圈数”或“反向走本次圈数”。每次从当时的停止位置计算目标。方向尚未标定为上升或下降。轴2旧的无限JOG按钮停用，其他轴原始运动参数未改变。
6. 查看“本次实际增量”和现场丝杆/升降运动。这里显示的是编码器折算电机圈数，不是丝杆圈数或升降毫米。

“停止轴2”下发轴2停止请求；运动中切换窗口或关闭窗口也会请求停止轴2。关闭窗口需等到停止反馈，之后再次关闭。停止不会主动断使能。软件停止依赖通信，不能替代现场物理急停。

加减速沿用原Demo的1 count/ms²，120rpm为速度上限而非全程平均速度。短行程可能达不到该速度；例如理论上1电机圈约1.024秒（含加减速），2圈约1.524秒。实际结果以现场反馈为准。

## 诊断及限制

- 下令前检查四轴停止、报警/限位、轴2使能、静止规划与反馈差、驱动状态与模式、编码器和电子齿轮、卡端比例，以及读取超时。配置不符时拒绝运动，不自动改写配置。
- 新目标使用新读到的位置加本次增量，检查32位溢出。重复点击不能叠加正在执行的指令。
- 运行时显示规划位置、实际反馈、两者差、状态字和本次实际圈数；采样/命令/错误写入程序旁的`logs`目录。
- 所有轴2启动与停止返回码都检查。停止请求失败或反馈读取失败时，不将运动状态直接清除为已停止。
- 监测依赖当前通信和Windows应用，不是独立安全控制器。抱闸时序检查不证明抱闸接线、机械释放和承载能力。
- 本次只完成编译、模拟行为及未连接界面验证；机械导程、传动比、方向、可用行程与120rpm实机表现仍由现场测试确认。
